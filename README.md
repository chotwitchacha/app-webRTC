# Meeting App

แอปห้องประชุมวิดีโอหลายคน (WebRTC แบบ Mesh) เขียนด้วย Java

- **แอป Android** สำหรับผู้สร้างห้อง: สร้างลิงก์ห้องประชุม แชร์ให้คนอื่น แล้วเริ่มประชุม
- **ผู้เข้าร่วม** เปิดลิงก์เชิญแล้วเข้าประชุมผ่านเบราว์เซอร์ได้ทันที ไม่ต้องติดตั้งแอป
- รองรับไม่เกิน 6 คนต่อห้อง

## ทดลองใช้งาน

**ผู้สร้างห้อง (Android 7.0 ขึ้นไป)**

1. เปิดหน้า [Releases](../../releases/latest) บนมือถือ แล้วดาวน์โหลดไฟล์ `.apk` เวอร์ชันล่าสุด
2. เปิดไฟล์แล้วกดติดตั้ง ถ้ามือถือถาม ให้อนุญาต "ติดตั้งแอปที่ไม่รู้จัก" สำหรับเบราว์เซอร์หรือแอปไฟล์ที่ใช้เปิด
3. เปิดแอป กด **สร้างลิงก์ห้องประชุม** แล้วกด **แชร์ลิงก์** ส่งให้คนที่จะคุยด้วย
4. กด **เริ่มประชุม** และอนุญาตกล้องกับไมโครโฟน

**ผู้เข้าร่วม** เปิดลิงก์ที่ได้รับใน Chrome หรือ Safari แล้วกด **เข้าร่วมผ่านเบราว์เซอร์**
ถ้าเปิดจาก LINE หรือ Facebook แล้วกล้องใช้ไม่ได้ ให้กดเมนูเลือกเปิดในเบราว์เซอร์ก่อน

> ถ้าลบแอปแล้วติดตั้งใหม่ จะกลับเข้าห้องเดิมในฐานะผู้สร้างห้องไม่ได้ ต้องสร้างลิงก์ใหม่
> เซิร์ฟเวอร์ใช้แพ็กเกจฟรี การสร้างลิงก์ครั้งแรกหลังไม่มีคนใช้นาน ๆ อาจใช้เวลาเกือบนาที

## สำหรับนักพัฒนา

### Build บนคอมตัวเอง

1. เปิดโปรเจกต์ใน Android Studio
2. คัดลอกค่าใน `local.properties.example` ไปต่อท้าย `local.properties` แล้วใส่ `CREATE_ROOM_KEY`
   (ต้องตรงกับตัวแปร `CREATE_ROOM_KEY` ของเซิร์ฟเวอร์)
3. กด Run

### ปล่อยเวอร์ชันใหม่

ตั้ง Secrets ใน **Settings → Secrets and variables → Actions** ให้ครบก่อน (ดูรายชื่อในไฟล์
`.github/workflows/android-release.yml`) แล้วสร้าง tag:

```bash
git tag v1.0.0
git push origin v1.0.0
```

GitHub Actions จะ build APK แล้วสร้าง Release พร้อมไฟล์ให้ดาวน์โหลดอัตโนมัติ
ทุกครั้งที่ปล่อยเวอร์ชันใหม่ให้เพิ่ม `versionCode` ใน `app/build.gradle.kts` ด้วย

### ห้าม push ขึ้น GitHub

`local.properties`, ไฟล์ keystore (`*.jks`) และรหัสผ่านต่าง ๆ (กันไว้ใน `.gitignore` แล้ว)
